# 筋トレ管理 イラスト作業 開始プロンプト（毎晩用）

自宅のClaude Desktopで、その夜の作業を始めるときに最初に貼る。
（このあとに、制作リストMDの「共通ルール」と、その日のバッチのブロックを続けて貼る。または、MDをそのまま添付する）

```
今夜の「筋トレ管理」フォームイラスト作業を始めます。
添付の「筋トレ管理 Claude Design 画像リストとプロンプト」MDに沿って進めてください。

【始める前の確認】
1. 今の時刻を確認してください。21:00より前なら「まだ作業時間ではありません」と言って止めてください。
   水曜日は23:30より前なら止めてください。
2. MDの制作リストの「状態」欄を見て、⬜（未着手）か🟡（作成中）が残っている最初のバッチを選んでください。
   - バッチ0が✅になっていない間は、バッチ0以外に進まないでください（タッチを決めてから量産する）
   - バッチ4（懸垂機）は保留なので、私が「懸垂機が来た」と言うまで飛ばしてください
3. 今夜やる種目を、多くても5〜7種目で提案してください。私がOKしてから作り始めます。

【作るとき】
- MDの「共通ルール」を必ず守ってください。
- 種目ごとに2コマのSVGを、ファイル名つき（{ファイル名}_1.svg / _2.svg）で出してください。
- 最後に、全種目の2コマを「→」でつないだプレビューを、92px表示と大きい表示の両方で見せてください。

【終わるとき】
- 今夜できた種目の一覧と、制作リストで ✅ にする行を書き出してください。
- 92pxで読みにくい絵があれば、そのことと直し方を隠さず書いてください。
- 次回やるバッチを1行で書いてください。
```
