新しいセッションの最初に流す。**調べ直しに使うトークンを節約するためのコマンド。**

以下を順に確認し、最後にまとめて報告する。各項目は独立しているので並列で取得してよい。

## 1. 案件の未決事項

Notion 案件ナレッジDB（`collection://83809175-1106-4706-bdd5-86c8931173c4`）から、
`状態` が `検討中` のレコードだけを引く。要約だけ読む。本文は必要なものだけ開く。

```sql
SELECT url, "項目", "要約", "案件", "種別"
FROM "collection://83809175-1106-4706-bdd5-86c8931173c4"
WHERE "状態" = '検討中'
```

## 2. 自宅PCの運用状況

Notion「🧭 自宅PC自動化 運用カード」（`3d893ac16efe810ea52ad8a9eaa333dc`）の
**未解決セクションだけ**を読む。全文は読まない。

## 3. 取込パイプラインが生きているか

`/取込確認` と同じ判定を行う（詳細はそのコマンドを参照）。結論だけ報告する。

## 4. 開いているPR

`simula-cra/my-workspace` と `simula-cra/obsidian-vault` のopen PRを確認する。
CIが赤いもの、レビュー待ちのものがあれば名指しする。

## 報告の形

長く書かない。以下の形で、**動くべきものが動いているか**を先に書く。

```
■ 動いている / 止まっている
（取込パイプラインの状態。判断根拠の日付も添える）

■ 手が止まっている未決（3件まで）
（誰の判断待ちかを明記する。クラさん待ちなのか、私がやるべきなのか）

■ 開いているPR
（あれば。なければ書かない）
```

未決が5件を超えていたら、全部並べずに「重いもの3件」に絞って、残りは件数だけ言う。
